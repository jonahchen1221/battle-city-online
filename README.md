# Battle City Online

NES《坦克大战》复刻，支持 1–4 人局域网合作。TypeScript + Canvas + Node，服务器权威联机，不用任何外部图片资产（像素画全部代码生成）。

## 局域网开玩

```bash
npm install
npm run lan
```

启动后终端会打印局域网地址（如 `http://192.168.1.87:8080`）和固定本地局链接 `http://192.168.1.87:8080/?local`。同一 WiFi 的朋友打开这个 `?local` 链接、或在首页选 LOCAL GAME，不用房间码就能进同一间房；LOCAL 大厅内任何玩家都可以用方向键选择第 1–40 关。也仍可用 CREATE ROOM / JOIN ROOM 开独立房间，建房时可用方向键或直接输入数字设置起始关卡。全员 Enter 准备，房主 S 开局。

键位：方向键 / WASD 移动，Space 或 J 开火（长按连发），P 暂停，Enter 确认/准备。

手柄：十字键 / 左摇杆移动，A/B/X 开火，Start 开始，Select 暂停；菜单里 A 确认 / B 返回（房间码仍需键盘输入或粘贴）。

## 开发

```bash
npm run dev         # vite 客户端（单机调试）
npm run dev:server  # 联机服务器（tsx watch 热重载，端口 8080）
npm run typecheck   # 类型检查（提交前必须通过）
```

改代码前先读 [CLAUDE.md](CLAUDE.md)：架构铁律（`src/game/` 是纯模拟层）、坐标规格、美术约定都在里面。

## 多人规则（与 NES 原版的差异）

- 团队制：一人清完敌人即全队过关；新关卡全员满命复活。
- 多人初始 5 条命（单机保持原版 3 条）；生命耗尽自动向随机队友借 1 条（队友需剩 ≥2）。
- 友军火力：击中队友不掉血，但对方会被冻结 3 秒。
- 敌军拾取 TIMER 时全体玩家冻结 3 秒；玩家拾取时仍冻结敌军 10 秒。
- 钻头（DRILL，银色 D）：拾取后该坦克**所有武器**的子弹都能击穿钢块（激光穿钢后继续飞），
  鹰巢与战场边界仍打不穿；效果持续到坦克被击毁，关内复活即失效。
- 跨关继承：过关时各人的 star 等级、当前武器与钻头一并带入下一关；关内被击毁复活则全部归零。
- **关卡循环：普通 → 护送 → Boss → 对战，共 40 关**，通关第 40 关回卷第 1 关。
  每四关为一“组”（共 10 组），第 t 组的普通关用第 t 张普通图与第 t 档敌军编成。
  逐组变难：地形更硬（钢墙 / 水路 / 冰面 / 迷宫），威力与装甲坦克的比例只增不减，
  敌军出生间隔由 190 帧压到 90 帧。
- 护送关是每组的第 2 关（第 2 / 6 / 10 … 38 关）；十张独立的 2×3 大地图分别采用桥头争夺、运河折返、冰原交火、双河堡垒、分段要塞、终局回廊、蛇形峡谷、群岛船坞、风暴棋盘和回钩堡垒布局。除了连续横切、环绕和短暂反向折返，各图还采用不同的护卫带地形、0–4 道城门节奏和敌军投入方向：冰原要求在冰面护卫，双河左右交替夹击，分段要塞连续攻门，群岛固定提供船以开放水路包抄，回钩堡垒会从车后增援。每个护送位覆盖连续 2 格：1–2 人局只有 1 个位置、站 1 人即可；3–4 人局有左右 2 个位置，只占一侧为半速、两侧齐备恢复全速。
  车尾另有一条**推车位**（与车身同宽、纵深 1 个坦克位的虚线框）：任何存活玩家站进去都算推车手，
  每人为车速贡献 0.5 档动力，最多计 2 名。**推车是独立动力**：护卫位空着时车尾 1 人推 = 半速、
  2 人推 = 全速；与护航叠加时满护航 + 2 人推 = 2 倍速。被路障挡住或已到站时推了也不动；断线玩家不计。
  车速公式为「基础速度 × (护卫位占比 + 0.5 × 推车手数)」，推车位随车辆转向一起旋转。车队遇路障/敌军也会停车。所有敌军掉队且无人看见时会按本图的投入方向重新参战，原始编成耗尽后持续增援（停车时增援减速）；普通关仍是有限 20 辆。HUD 同时显示剩余时间与完整路线行驶百分比。车辆没有血量且不会被攻击摧毁，但会拦住所有子弹；3 分钟倒计时归零即失败。扳手增加 15 秒，铲子暂停计时 20 秒。
- **Boss 关（每组第 3 关：第 3 / 7 / 11 … 39 关，第 39 关为最终战）**：竞技场没有鹰巢，
  过关条件改为击杀 32×32（普通坦克 2×2、共 4 格大小）的 Boss；它会在场内追踪玩家，
  遇到砖墙会用双发破障激光清路（每 2 秒一轮），钢墙打不穿，只能绕行 —— 掩体能长期守住。
  Boss 对坦克是实心障碍，小兵的子弹打在它身上会被吸收，只有玩家的火力能扣血
  （激光 −2，其余武器 −1）。
- **十战十场 + 技能解锁**：十位 Boss 各有独立的地形、Boss / 玩家入场点与主场打法：
  开放弹幕、错列换道、诱导冲撞、可破坏街区、断桥夹击、双环雷道、磁力锚点、纵向水闸、
  阶段折线和最终王座。第 3 / 4 / 7 / 9 张图在半血后还会永久打开部分地形；招牌技能在对应
  攻击池中拥有更高权重，但仍保留随机变化。数值同步爬升：血量 = 100 + 10×(序号−1) +
  每多一名玩家 60，攻击间隔按序号线性收紧到 86.5%。
  技能按 Boss 序号**累积**解锁（解锁后永不移除）：1 号为基础组（整列粗激光 / 8 向放射 / 三连瞄准射，
  二阶段追加 16 向旋转弹幕与双列激光），2 号起加**弹幕墙**（整排子弹只留一个 32px 缺口），
  3 号加**蓄力冲撞**（预警 45 帧后 4px/帧碾过来，粉碎沿途砖块；撞钢眩晕 90 帧、撞边界 45 帧 ——
  骗它撞墙就是最大的免费输出窗口），4 号加**迫击炮雨**（4 个落点闪烁 48 帧后炸开 16×16），
  5 号加**召唤援军**（两侧瞬间闪现 2 只小兵，全场敌军硬上限 6 只），6 号加**沿途布雷**
  （移动时每 90 帧在车尾丢一枚地雷，武装 60 帧后触之即死，可以用子弹提前引爆安全排雷），
  7 号加**磁力牵引**（90 帧内持续把玩家拖向 Boss，同时每 30 帧一圈弹幕），
  8 号加**横扫激光**（激光列朝目标半场横扫，站到另一半场就安全），9 号全池解锁 + 间隔继续收紧，
  10 号残血 25% 以下进入**狂暴**：攻击间隔再 ×0.75、弹幕弹速 ×1.2。
  所有弹幕都是普通敌弹，可以用子弹打掉；每个新技能都有醒目的预警，全部可躲。
- 单机局减压：一阶段 Boss 定点不动（只放弹幕，也不破障），二阶段起才慢速追踪；多人局两阶段都全速追踪。
- Boss 关的小兵无限补充，场上上限随人数为 2/3/4/5 只（最终战第 39 关为 power/smart，其余 Boss 关为 basic/fast），每 400 帧一只、
  每第 2 只携带道具。Boss 关的中立道具改用专属池：2 枚星 + 头盔 + 战靴 + 1 件随机武器。
- **对战关（每组第 4 关）**：N 名玩家对 N 台智能坦克，没有鹰巢。每台 AI 都有独立席位和与
  对应玩家相同的开局命数，被击毁后在原席位复活；耗尽全部 AI 命数才胜利。AI 优先一对一压制，
  对位玩家离场后才分流支援队友，并会规划中距离射击位、分散侧翼和躲避来弹。6 张专用图依次为
  十字火网、三桥争夺、迷雾棋盘、冰环换位、阶梯突破和四堡夺点，在 10 个循环组中顺序轮换。
- 中立道具对 Boss 同样生效：时钟（TIMER）冻结 Boss 2 秒（期间不动、不破障、攻击计时全停，仍可被打），
  沙漏（HOURGLASS）让 Boss 半速 12 秒。
