# Battle City Online

NES《坦克大战》复刻，支持 1–4 人局域网合作。TypeScript + Canvas + Node，服务器权威联机，不用任何外部图片资产（像素画全部代码生成）。

## 局域网开玩

```bash
npm install
npm run lan
```

启动后终端会打印局域网地址（如 `http://192.168.1.87:8080`）。首页可在 NAME 一项设置 2 位字母或数字组成的名字（自动保存在浏览器中）。房主用该地址打开、CREATE ROOM，然后把地址栏的 `?room=房间码` 链接发给同一 WiFi 的朋友，点开即进房；也可在大厅按 C 复制链接。全员 Enter 准备，房主 S 开局。

键位：方向键 / WASD 移动，Space 或 J 开火，P 暂停，Enter 确认/准备。

手柄：十字键 / 左摇杆移动，A/B/X 开火，Start 开始，Select 暂停；菜单里 A 确认 / B 返回（房间码仍需键盘输入或粘贴）。

## 开发

```bash
npm run dev         # vite 客户端（单机调试）
npm run dev:server  # 联机服务器（tsx watch 热重载，端口 8080）
npm run typecheck   # 类型检查（提交前必须通过）
```

改代码前先读 [CLAUDE.md](CLAUDE.md)：架构铁律（`src/game/` 是纯模拟层）、坐标规格、美术约定都在里面。

## 多人规则（与 NES 原版的差异）

- 团队制：一人清完敌人即全队过关；新关卡全员满命复活。
- 多人初始 5 条命（单机保持原版 3 条）；生命耗尽自动向随机队友借 1 条（队友需剩 ≥2）。
- 友军火力：击中队友不掉血，但对方会被冻结 3 秒。
- 敌军拾取 TIMER 时全体玩家冻结 3 秒；玩家拾取时仍冻结敌军 10 秒。
- 钻头（DRILL，银色 D）：拾取后该坦克**所有武器**的子弹都能击穿钢块（激光穿钢后继续飞），
  鹰巢与战场边界仍打不穿；效果持续到坦克被击毁，关内复活即失效。
- 跨关继承：过关时各人的 star 等级、当前武器与钻头一并带入下一关；关内被击毁复活则全部归零。
- 移动关与普通关交替出现（移动 → 普通 → 移动）；六个移动关使用不同的 2×3 大地图和路线，部分路线会转弯。至少一名玩家进入车辆左/右护卫标记位才会开车，车队遇路障/敌军也会停车。普通敌军会维持在车辆周围作战，远远掉队且无人看见时会从前方重新投入。敌弹会损伤车辆，扳手修复 3 点，铲子提供临时护盾。
- 共 12 关循环，逐关变难：地形更硬（钢墙 / 水路 / 冰面 / 迷宫），威力与装甲坦克的比例只增不减，
  敌军出生间隔由 190 帧压到 90 帧。
- **Boss 关（第 6 关与第 12 关最终战）**：竞技场没有鹰巢，过关条件改为击杀 32×32（普通坦克
  2×2、共 4 格大小）的 Boss；它会在场内追踪玩家，遇到砖墙或钢墙会用双发破障激光清路。
  Boss 对坦克是实心障碍，小兵的子弹打在它身上会被吸收，只有玩家的火力能扣血
  （激光 −2，其余武器 −1；血量 = 100 + 每多一名玩家 60）。
- Boss 的攻击有前摇醒目的整列粗激光、8 向放射弹幕与三连瞄准射；血量掉到一半会进入第二阶段
  （配色转红、出手更快），追加 16 向旋转弹幕与双列激光。所有弹幕都是普通敌弹，可以用子弹打掉。
- Boss 关的小兵无限补充但场上至多 2 只（第 6 关 basic/fast，第 12 关 power/smart），每第 4 只
  携带道具；中立道具照常每关必刷。
