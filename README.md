# Battle City Online

NES《坦克大战》复刻，支持 1–4 人局域网合作。TypeScript + Canvas + Node，服务器权威联机，不用任何外部图片资产（像素画全部代码生成）。

## 局域网开玩

```bash
npm install
npm run lan
```

启动后终端会打印局域网地址（如 `http://192.168.1.87:8080`）和固定本地局链接 `http://192.168.1.87:8080/?local`。同一 WiFi 的朋友打开这个 `?local` 链接、或在首页选 LOCAL GAME，不用房间码就能进同一间房。也仍可用 CREATE ROOM / JOIN ROOM 开独立房间。全员 Enter 准备，房主 S 开局。

键位：方向键 / WASD 移动，Space 或 J 开火，P 暂停，Enter 确认/准备。

手柄：十字键 / 左摇杆移动，A/B/X 开火，Start 开始，Select 暂停；菜单里 A 确认 / B 返回（房间码仍需键盘输入或粘贴）。

## 开发

```bash
npm run dev         # vite 客户端（单机调试）
npm run dev:server  # 联机服务器（tsx watch 热重载，端口 8080）
npm run typecheck   # 类型检查（提交前必须通过）
```

改代码前先读 [CLAUDE.md](CLAUDE.md)：架构铁律（`src/game/` 是纯模拟层）、坐标规格、美术约定都在里面。

## 多人规则（与 NES 原版的差异）

- 团队制：一人清完敌人即全队过关；新关卡全员满命复活。
- 多人初始 5 条命（单机保持原版 3 条）；生命耗尽自动向随机队友借 1 条（队友需剩 ≥2）。
- 友军火力：击中队友不掉血，但对方会被冻结 3 秒。
- 敌军拾取 TIMER 时全体玩家冻结 3 秒；玩家拾取时仍冻结敌军 10 秒。
- 钻头（DRILL，银色 D）：拾取后该坦克**所有武器**的子弹都能击穿钢块（激光穿钢后继续飞），
  鹰巢与战场边界仍打不穿；效果持续到坦克被击毁，关内复活即失效。
- 跨关继承：过关时各人的 star 等级、当前武器与钻头一并带入下一关；关内被击毁复活则全部归零。
- **关卡循环：普通 → 护送 → Boss 三段循环，共 30 关**，通关第 30 关回卷第 1 关。
  第 n 关的类型由 n % 3 决定：余 1 为普通关、余 2 为护送关、余 0 为 Boss 关；
  每三关为一“组”（共 10 组），第 t 组的普通关用第 t 张普通图与第 t 档敌军编成。
  逐组变难：地形更硬（钢墙 / 水路 / 冰面 / 迷宫），威力与装甲坦克的比例只增不减，
  敌军出生间隔由 190 帧压到 90 帧。
- 护送关是每组的第 2 关（第 2 / 5 / 8 … 关）；六张 2×3 大地图分别采用桥头争夺、运河折返、冰原交火、双河堡垒、分段要塞和终局回廊布局，并按护送次序轮换。每个护送位覆盖连续 2 格：1–2 人局只有 1 个位置、站 1 人即可；3–4 人局有左右 2 个位置，必须两边同时有人。车队遇路障/敌军也会停车。所有敌军掉队且无人看见时都会从前方重新投入，原始编成耗尽后持续增援（停车时增援减速）；普通关仍是有限 20 辆。HUD 同时显示剩余时间与完整路线行驶百分比。车辆没有血量且不会被攻击摧毁，但会拦住所有子弹；3 分钟倒计时归零即失败。扳手增加 15 秒，铲子暂停计时 20 秒。
- **Boss 关（每组第 3 关：第 3 / 6 / 9 … 30 关，第 30 关为最终战）**：两张竞技场按组号奇偶交替
  （奇数组 A、偶数组 B）。竞技场没有鹰巢，过关条件改为击杀 32×32（普通坦克
  2×2、共 4 格大小）的 Boss；它会在场内追踪玩家，遇到砖墙会用双发破障激光清路（每 2 秒一轮），
  钢墙打不穿，只能绕行 —— 掩体能长期守住。
  Boss 对坦克是实心障碍，小兵的子弹打在它身上会被吸收，只有玩家的火力能扣血
  （激光 −2，其余武器 −1；血量 = 100 + 每多一名玩家 60）。
- Boss 的攻击有前摇醒目的整列粗激光（前摇 1.5 秒、持续 0.5 秒）、8 向放射弹幕与三连瞄准射；
  血量掉到一半会进入第二阶段（配色转红、出手更快），追加 16 向旋转弹幕（2 波）与双列激光。
  所有弹幕都是普通敌弹，可以用子弹打掉。
- 单机局减压：一阶段 Boss 定点不动（只放弹幕，也不破障），二阶段起才慢速追踪；多人局两阶段都全速追踪。
- Boss 关的小兵无限补充，场上上限随人数为 2/3/4/5 只（最终战第 30 关为 power/smart，其余 Boss 关为 basic/fast），每 400 帧一只、
  每第 2 只携带道具。Boss 关的中立道具改用专属池：2 枚星 + 头盔 + 战靴 + 1 件随机武器。
- 中立道具对 Boss 同样生效：时钟（TIMER）冻结 Boss 2 秒（期间不动、不破障、攻击计时全停，仍可被打），
  沙漏（HOURGLASS）让 Boss 半速 12 秒。
